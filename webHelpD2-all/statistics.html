Statistics Overview

The Statistics Module of the Analytics Platform provides a comprehensive view of activity across a variety of decentralized identity networks, including PRISM and the popular Indy-Networks Sovrin, IDunion, Indicio, BC Government, and CANdy. It offers unique insights into these networks, enabling professionals to monitor key metrics, follow trends, and make data-driven decisions. As the only platform providing in-depth views into DID PRISM and other major decentralized networks, the Statistics Module is an invaluable resource for anyone working in the decentralized identity space.

Through the Statistics Module, you can:

  • Monitor network activity: Track the creation, update, and deactivation of DIDs in real-time across various networks.

  • Analyze cryptographic suite usage: Understand which cryptographic methods are prevalent in the network over time.

  • Track service type adoption: See which services, such as DIDComm v1 or DIDComm v2, are being used on each network.

  • Examine node operations: View the active nodes performing operations on the network and their impact on decentralized identity ecosystems.

  • Filter recent operations: Explore recent create, update, and deactivate operations on the network with detailed, real-time data.

Features

Network Overview

The Networks Overview page provides a visual representation of network usage. You can compare activity on production networks with test/development environments, gaining insights into potential future adoption trends while being mindful of automated testing activities that may distort impressions of real-world usage.

Detailed Network Information

Each network has a dedicated page with detailed insights, including:

  • Network Activity: Track DID operations (create, update, deactivate) over time.

  • DIDs Created: Monitor the cumulative number of DIDs generated on a network.

  • Crypto Suite Usage: Understand which cryptographic suites are in use across the network.

  • Service Type Usage: Analyze the adoption of different service types, such as DIDComm.

  • Active Nodes: For PRISM networks, explore which nodes are active and their role in the network's operation.

  • Recent Operations: Filter operations by type (create, update, deactivate) and explore detailed metadata, such as transaction hashes or operation IDs, specific to each network.

Supported Networks

The Statistics Module provides insights into a wide range of decentralized identity networks, including:

  • DID PRISM on the Cardano Blockchain.

  • Sovrin, a nonprofit network focused on self-sovereign identity.

  • IDunion, a European-based network ensuring compliance with GDPR and other European regulations.

  • Indicio, a decentralized network that supports scalable, mission-critical identity solutions.

  • BC Government's BCovrin TestNet, used extensively for testing decentralized identity applications.

  • CANdy, a Canadian decentralized identity network supporting cross-regional collaboration.

Each network is represented by real-time data on DID operations, cryptographic suite adoption, and service usage, all of which are continuously updated to provide the most up-to-date information.

Users can log in to access additional features, such as the ability to refresh data in real-time and access historical versions of DIDs for detailed analysis. Filters allow users to narrow down datasets, making it easier to follow specific trends or prepare for further analysis in the Analytics Module.
